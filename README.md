# cexufu.github.io

Personal site and blog of Cexu (Tony) Fu. Built by GitHub Pages' own Jekyll from the `main` branch, with no theme.

- Home page: `index.html`
- Notes (blog): add a Markdown file to `_posts/` named `YYYY-MM-DD-title.md`. Add `math: true` to its front matter to render LaTeX with KaTeX.
- Styles and scripts: `assets/css/site.css`, `assets/js/site.js`
- Layouts: `_layouts/`, shared head and navigation: `_includes/`
